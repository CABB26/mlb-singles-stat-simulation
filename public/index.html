    Inside the V2 model FEATURES → PROBABILITY → CORRELATED SIMULATION

    Stable baseline. Season HR/PA begins with a 3% prior over 100 plate appearances so tiny samples do not dominate. The model works on the log-odds scale instead of stacking arbitrary points.

    Contact-quality layer. Savant barrel%, hard-hit% and average EV adjust the baseline. The adjustment grows with batted-ball sample size and is capped to prevent one noisy metric from hijacking the forecast.

    Pitcher matchup layer. MLB’s probable starter and season HR allowed per batter faced are shrunk toward a neutral 3% prior. Only part of the starter signal is applied because hitters can face the bullpen later.

    Context layer. Batting-order slot changes opportunity. Optional HR Context files can apply park, weather and pitch-fit multipliers, while the machine stays neutral when those inputs are absent.

    Monte Carlo layer. Each trial adds a shared game-environment shock plus player uncertainty, then simulates each plate appearance. This creates correlated outcomes for hitters in the same game and produces 1+ HR, 2+ HR and expected-HR distributions.

    Combination optimizer. The machine simulates every three-player combination from the leading hitter pool. The headline top three remain the three strongest individual 1+ HR probabilities; the combo board separately shows tournament-style three-player ceiling.

    These are model estimates, not guarantees. Refresh lineups near lock and treat unconfirmed hitters carefully.

    Data and upload rules

    DraftKings IDs remain contest IDs and are never treated as MLB IDs. Matching requires normalized player name, team and opponent. Ambiguous, stale or unmatched records are reported instead of silently forced together.

    OUT, O, IL and inactive statuses exclude a hitter. DTD remains visible. Uploaded CSV content is kept in memory in the browser tab and is never executed as code.
