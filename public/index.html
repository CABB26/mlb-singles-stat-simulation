    Inside the model HR / PA → GAME PROBABILITY → SIMULATION

    A transparent baseline. The only performance rate is season home runs divided by plate appearances. We stabilize small samples with a fixed 3% prior over 100 plate appearances: (HR + 3) / (PA + 100). The prior is an assumption, not a measured current league average.

    For N assumed plate appearances, the chance of at least one home run is 1 − (1 − rate)N. Each simulation draws N independent home-run events. Rankings use the exact probability so random simulation noise cannot shuffle the picks. A fixed seed makes results reproducible.

    Live mode covers today in Eastern Time and only upcoming regular-season or postseason games. Announced batting orders are used when available. Unconfirmed hitters may not play. Doubleheader players appear once, with one game’s probability. Missing feeds make coverage incomplete and are reported.

    These estimates assume the same number of plate appearances for every hitter. They do not account for opposing pitchers, ballparks, weather, platoon splits, or injuries. They are not calibrated forecasts or guarantees. Simulation percentages measure this model, not prediction accuracy.

    How uploads and Savant work

    DraftKings IDs are kept as contest IDs and are never treated as MLB IDs. Upload matches require normalized full name, team and opponent. Ambiguous or unmatched players appear in the match report. Stale file dates stop the run. DraftKings is the pool restriction; the cheatsheet is optional context and does not exclude players just because it lacks a row.

    OUT, O, IL and inactive upload statuses exclude a hitter. DTD remains visible for review. Imported batting order is context only; MLB’s posted lineup controls lineup eligibility. Fantasy points, salary and DraftKings average points never become home-run probabilities.

    Baseball Savant provides current-season barrel rate per batted ball, hard-hit rate, average exit velocity in mph and batted-ball count. Metrics join by MLB player ID and do not change ranking. Small samples are labeled. The feed may lag games, and the server may cache it for 30 minutes; the displayed time is retrieval time, not the last pitch included.

    Missing Savant values display as unavailable. If Savant fails, the app explicitly reports the failure and keeps the MLB baseline. Uploaded CSV contents stay in memory in your tab and clear on reload. CSV fields are data, never instructions or executable formulas.
